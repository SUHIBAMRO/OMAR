# Job `batch_20261125_3jobs`: step by step

1. **On your computer**, download (opens in the browser, lands in Downloads):
   https://github.com/SUHIBAMRO/OMAR/raw/claude/claude-code-question-d307wp/transfer/batch_20261125_3jobs.tar.gz
2. **On your computer**, in a new PowerShell window:
   ```
   scp -O $HOME\Downloads\batch_20261125_3jobs.tar.gz <login>@cslogin.tu-ilmenau.de:~/
   ```

## Before step 3 (once): check the Python packages on the cluster

On the cluster, one line at a time:
```
source ~/miniconda3/etc/profile.d/conda.sh
conda activate omar
python -c "import gmsh, skfem, pypardiso, sympy; print('ok')"
```
If it prints `ok`, continue with step 3. If it prints an error, run once:
```
pip install gmsh==4.13.1 scikit-fem==12.0.2 pypardiso==0.4.7 sympy==1.14.0
```
and check again. If `import gmsh` still fails (a missing system library), paste the error into the chat.

3. **On the cluster** (after `ssh <login>@cslogin.tu-ilmenau.de`), one line at a time:
   ```
   md5sum ~/batch_20261125_3jobs.tar.gz
   ```
   It must print `9428977744c73be914a70145af143166`. Then:
   ```
   cd ~/OMAR && tar xzf ~/batch_20261125_3jobs.tar.gz && cd Practical_Examples
   bsub -gpu "num=1:mode=exclusive_process" -q BatchGPU -R "span[hosts=1] rusage[mem=120000]" -n 8 -W 24:00 -o batch_20261125_3jobs.%J.out -e batch_20261125_3jobs.%J.err < batch_20261125_3jobs_job.sh
   ```
   Expected: `Job <number> is submitted to queue <BatchGPU>.`
4. **When `bjobs` no longer lists it**, for each output:
   ```
   cd ~/OMAR/Practical_Examples/omar_pfem/verification_agent
   md5sum <output>
   cat <output>
   ```
   and paste both into the chat. Outputs: cluster_jobs/ladder_plate_hole_quarter_3d_pe_P232_result.json, cluster_jobs/mms_cook_3d_Q2_P2_n32_result.json, cluster_jobs/mms_nh_plate_hole_3d_pe_Q2_n32_result.json
