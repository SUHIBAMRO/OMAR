# Start here

Before doing anything else in this repo, read `PROJECT_STATUS.md` at the
repo root. It is the single source of truth for what's done, what's in
progress, and what's still pending on this project (PFEM/Transolver
hyperelasticity neural-operator report for Omar Amro, advised by Prof.
Timon Rabczuk). Chat history resets between sessions; this file does not.

Update `PROJECT_STATUS.md` whenever a task finishes or a new one starts,
and commit+push the update, so the next session (or the next `claude.ai`
tab) picks up exactly where this one left off.
